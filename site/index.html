Install

zig fetch --save=z_numeral https://github.com/carlos-sweb/z-numeral/archive/75ae970a92c164c0dd0a9474a26da64308eb6723.tar.gz

Format with a pattern

const numeral = @import("numeral");

var buffer: [128]u8 = undefined;
const result = try numeral.formatBuf(&buffer, 1234.5,
    numeral.pattern("0,0.00"));
// result: "1,234.50"

Use typed options or patterns for numbers, currency, percentages, bytes, ordinals, and durations.
